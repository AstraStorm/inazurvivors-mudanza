# InaZurvivors · Mudanza

Página temporal (hasta el 13 de noviembre de 2026) para que quien jugaba como invitado en
`astrastorm.github.io/InaZurvivors/` se lleve su partida a https://inazurvivors.com/.

Vive en el mismo origen que la dirección antigua (`astrastorm.github.io`), así que puede leer la partida guardada en el
navegador, y la manda dentro del enlace (`#mudanza=…`, que no llega a ningún servidor) a inazurvivors.com. El juego la
importa sin sobrescribir nada: si allí ya hay progreso, el jugador elige y la otra copia queda como respaldo.
